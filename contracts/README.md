# contracts
مرز مشترک بین همه‌ی اجزا. فایل‌های JSON، مستقل از زبان.

- ساختاری (تثبیت‌شده): `contract.schema.json`، `core/v1/*`، `wire/v1/*`، `config/v1/*`.
- قرارداد خودت = فایل جدید `<حوزه>/v1/<عملیات>.contract.json` (ورودی/خروجی با JSON Schema، کدهای خطا، مثال‌ها، نمونه‌های منفی).
- در `v1` فقط فیلد اختیاری اضافه می‌شه؛ هر تغییر دیگه = `v2`.
