# cores
هر هسته یک پوشه‌ی مستقل با ساختار داخلی خودش (هر زبان، هر فناوری، هر پلتفرم، هر پروژه‌ی موجود).

- یک هسته هسته‌ی دیگه و `app/` رو نمی‌شناسه.
- یک هسته قابلیت‌هایی رو **ارائه می‌ده**؛ اینکه چه کسی صداش بزنه و به کدوم قابلیت خدمت کنه در `config/platform.json` تعیین می‌شه.
- حداقل: جواب‌دادن به `core.v1.describe` و `core.v1.health` و رعایت فرمت سیم (`contracts/wire/v1`).
